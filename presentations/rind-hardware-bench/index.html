SHA-512 oddity: ESP32-S3 and RP2040 publish more cycles than the 8-bit Uno. Shown as published. The Uno port uses the rolled SHA-512 loop from the RP2040 branch (c08c91ea); the ESP32-S3 and RP2040 rows are the base build. That rolled loop measured 3.42 M cycles on RP2040 in one unrepeated run (n=1), not used here.
rind rows only. Cycles: published for microcontrollers; for Pi 2 computed = ns × 0.9 GHz (clock recorded every round). µs: published for M1 Pro, Pi 5, Pi 2; computed = cycles ÷ MHz for microcontrollers. Pi 5 SHA rows: 1 run, clock probably 1.5 GHz but not checked then, so no cycles. Runs: README.md.
