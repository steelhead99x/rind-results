Edge cases · kixel-ai/rind#791 and #798 · merged 19 Nov

New tests for identity-point sums (#791) and the HPKE edge vectors (#798)

Hash-to-curve sums (#791)

  • main already refused a sum at infinity. The PR proves it and tightens the tests; no production behavior change.
  • Opposite-point sums go through P-256, P-384 and P-521, and through OPRF and VOPRF blinding and evaluation. Empty DSTs are refused.
  • 52 tests passed (hash_to_curve oprf::). Replacing the refusal with Ok(affine(point)) fails all six new identity tests.
  • CI on 11296db88: 44 checks pass.

HPKE edge vectors (#798)

  • The IETF revision of RFC 9180 added edge-case vectors as a Markdown appendix, so the vector sync tool could not fetch them.
  • All 46 hex literals appear verbatim in the appendix (hpkewg/hpke e298f94), checked by a script.
  • CI on 374202449: check (Haswell) ran the two new tests, both pass; 42 checks pass.
  • Tests and docs only.

CI and dev shell · kixel-ai/rind#796 and #876

Alerts fire only on a time-limit cancel; the dev shell runs the flake's rustfmt and clippy

CI alerts (#796, merged 18 Nov)

  • A job past its time limit ends "cancelled", not "timed out". Every scheduled cancel posted (14 in the week before), and a hung Release or Site deploy posted nothing.
  • Now one rule: post when a cancelled job carries GitHub's "exceeded the maximum execution time" annotation. If it cannot tell, it says so.
  • Checked on real runs: yes for fuzz, miri and mutants time-limit kills; no for a repository transfer and two Site deploys. sh/alert.sh check over 19 workflows.

Dev shell cargo shims (#876, merged 19 Nov)

  • Inside nix develop, Cargo ran cargo-fmt and cargo-clippy from a host rustup's $CARGO_HOME/bin. wasm clippy failed and rustfmt flagged untouched files.
  • Every dev shell now appends that directory to PATH, so the flake's tools win.
  • Control on main's flake prints SHIM fmt --version; the fixed head prints rustfmt 1.9.0-stable. CI: 27 checks pass, 11 skipped.
