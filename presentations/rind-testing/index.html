wasm and Ed25519 · kixel-ai/rind#797

Ed25519's 914 edge-case vectors and the memory-wipe checks now run on wasm, and in every CI run

  • No reference on wasm. aws-lc does not build there, so Ed25519 edge cases had nothing to compare with. Now a file records aws-lc's accept or reject for each of the 914 CCTV vectors, and every target checks rind against it.
  • Checks that could not run. The wipe checks panicked on purpose, and wasm aborts on a panic. They now return a result instead.
  • Not in the gate. These wasm tests ran only nightly. The cross lane of just ci now runs them under wasmtime.

Edge cases · kixel-ai/rind#791 and #798

Two edge cases that no test reached before: a hidden identity point, and an HPKE key that needs a second try

Hash-to-curve sums (#791)

  • During review, a test change showed that hiding an infinity sum by changing only one coordinate let an invalid point through.
  • Now the original infinity sum is refused, as before, and only the yes or no verdict is public.
  • Tests feed opposite points through all three curves and through OPRF and VOPRF.
  • 9 tests passed. No real message is known to reach this sum.

HPKE edge vectors (#798)

  • The IETF revision of RFC 9180 added edge-case vectors, in Markdown only, so the vector sync tool could not fetch them.
  • They are copied by hand into rind's HPKE tests: a P-256 key whose first candidate is too big, so it comes from the second; and empty or zero-byte inputs.
  • Only suites rind offers; the PSK vector's key half only.

CI alerts and the fork sync

A hung release now raises an alert, and the fork caught up with 29 upstream commits with Dart green on every OS

CI alerts (kixel-ai/rind#796)

  • GitHub ends a job that runs past its time limit as "cancelled", not "timed out". Release jobs had no limit, so a hung publish died silently after 360 minutes.
  • Now a release or scheduled run that is cancelled after it started posts an alert; one that cannot be sorted says so.
  • Checked: shellcheck, actionlint, sh/alert.sh check over 18 workflows.

Fork sync (steelhead99x/rind#134, merged)

  • Brings 29 upstream commits to the fork, including one CI job per Intel CPU model and the cargo-deny waiver for two unmaintained-crate notices (#840).
  • A follow-up commit fixes the HPKE row in TESTING.md that broke admin/testing.
  • Dart CI passed on all 8 jobs; dart-ios ran 25 of 25 integration tests.
